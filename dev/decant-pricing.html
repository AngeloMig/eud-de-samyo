Decant pricing, perfume by perfume

Each perfume has its own price per vial. A set costs the vials the customer picks, added up, the same as the vial picker on the site. Bottle prices come from FragranceX’s product pages in pesos (22 November 2026), using the 100 ml tester where one is listed. Click a source line to re-check it. Type your real price in a yellow box if you pay less or more: everything updates and is saved in this browser.

How every number is made. Cost per ml = bottle price ÷ bottle ml × (1 + shipping & duties) × (1 + pouring loss). Vial price = (ml × cost per ml + vial + label + box share) ÷ (1 − payment fee − margin), rounded up to ₱5. Set price = the vials picked, added up, minus the six-vial discount. Your cost for a set = perfume + vials + labels + one box. Profit = price − cost − payment fee; margin = profit ÷ price. Shipping to the customer is left out (they pay it).
